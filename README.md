# narutokinntoki Portfolio

HTML・CSSを学びながら制作する、1ページ構成の自己紹介ポートフォリオです。

## フォルダ構成

```text
.
├─ index.html       # ページの内容と構造
├─ css/
│  └─ style.css     # ページの見た目
└─ README.md        # 制作目的や構成の説明
```

## 制作ステップ

1. HTMLでページの内容と構造を作る
2. CSSで基本の色・文字・余白を整える
3. スマートフォンに対応する
4. 作品を追加しやすい形に整える
5. GitHubで公開する
